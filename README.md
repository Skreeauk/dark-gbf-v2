## Features

- Magna & Primal Guide in MDX

## Stack

- Framework: Next.js 16
- UI: shadcn/ui, Aceternity UI, Magic UI & more
- CSS: Tailwind CSS
- Docs: Fumadocs
- Hosting: Cloudflare Pages

## Getting Started

#### Local Development

```
git clone https://github.com/Skreeauk/dark-gbf-v2.git
cd dark-gbf-v2
npm i
npm run dev
```

#### Build

```
npm run build
```
